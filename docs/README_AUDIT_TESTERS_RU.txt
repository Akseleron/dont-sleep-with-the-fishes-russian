Тестовый аудит русификации Dont Sleep With The Fishes
=====================================================

Это НЕ игра. Это только тестовый патч и сборщик логов для русификации.

Используйте его только со своей купленной или уже имеющейся копией Dont Sleep With The Fishes v1.1.3.
Архив не содержит саму игру.

Как установить
--------------

1. Найдите папку, где лежит DontSleepWithTheFishes.exe.
2. Распакуйте ZIP с аудит-патчем прямо в эту папку.
3. В этой же папке должен появиться файл run_dswf_rus_audit.bat.

Как запустить тест
------------------

1. Запустите run_dswf_rus_audit.bat.
2. Играйте как обычно.
3. По возможности проверьте разные места:
   - главное меню и медали;
   - настройки;
   - рыбалку;
   - поиск в море;
   - инвентарь и предметы;
   - сломанные предметы и ремонт;
   - Row / помощь / состояние напарника;
   - ночные события;
   - журнал;
   - смерти и концовки.

Что фотографировать
-------------------

Скриншоты нужны только если вы видите:

- обрезанный текст;
- текст, который налезает на другой текст;
- странный или неудобный русский текст;
- английский текст на картинке/текстуре;
- что-то визуально сломанное.

Как собрать логи
----------------

1. Закройте игру.
2. Запустите collect_audit_logs.bat.
3. Если появится tester_notes.txt, можно написать туда короткие заметки.
4. Скрипт создаст файл вида:

   dswf_audit_logs_ИМЯКОМПЬЮТЕРА_ГГГГММДД_ЧЧММСС.zip

5. Отправьте этот ZIP обратно.

Важно
-----

- Не нужно устанавливать Python, Git или другие программы.
- Не нужно запускать командную строку вручную.
- Не редактируйте файлы BepInEx, если вас отдельно об этом не попросили.
- Не отправляйте папку игры целиком.
- Не отправляйте DontSleepWithTheFishes.exe или DontSleepWithTheFishes_Data.
