## What Changed

- Added `scripts/validate_runtime_visible_english.py`.
- Added `docs/v1_1_3_runtime_visible_english_allowlist.tsv`.
- Added a runtime visible-text reapply pass in `DswfRusRuntimeFix`.
- Runtime reapply loads `_AutoGeneratedTranslations.txt` and narrow `FishingRegex.txt` regexes from the installed game payload.
- Runtime reapply scans active visible `TMP_Text` and `UnityEngine.UI.Text` at a low interval and applies exact, normalized, regex, company-note, and ending friend-fate translations.
