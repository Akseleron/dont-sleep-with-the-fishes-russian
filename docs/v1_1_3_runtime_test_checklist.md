# v1.1.3 Runtime Test Checklist

Do not use this checklist to claim v1.1.3 support until a clean v1.1.3 game copy has been tested.

## Prepare Clean Copy

From the repository root:

```bash
.venv-tools/bin/python scripts/dev_prepare_v1_1_3_test_copy.py
```

This copies:

```text
/mnt/shared/Games/DontSleepWithTheFishes_v1_1_3/DontSleepWithTheFishes_v1_1_3_ItchRelease
```

to:

```text
game_runtime_test_v1_1_3
```

The target is ignored by git.

## Install Dev Payload

Default dev install does not patch Unity assets and does not apply offline textures:

```bash
.venv-tools/bin/python scripts/dev_install_to_game.py game_runtime_test_v1_1_3 --clean-bepinex --skip-textures
```

Expected installed files:

- `game_runtime_test_v1_1_3/BepInEx/`
- `game_runtime_test_v1_1_3/BepInEx/config/`
- `game_runtime_test_v1_1_3/BepInEx/plugins/`
- `game_runtime_test_v1_1_3/BepInEx/Translation/ru/Text/_AutoGeneratedTranslations.txt`
- `game_runtime_test_v1_1_3/BepInEx/Translation/ru/Text/FishingRegex.txt`
- `game_runtime_test_v1_1_3/run_dswf_rus.sh`
- `game_runtime_test_v1_1_3/dswf_rus_dev_install_report.txt`

## Launch Later

Do not launch during install validation. For runtime testing later:

```bash
cd game_runtime_test_v1_1_3
./run_dswf_rus.sh
```

The launcher sets:

```bash
WINEDLLOVERRIDES="winhttp=n,b"
```
