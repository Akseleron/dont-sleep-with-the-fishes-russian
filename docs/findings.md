# Russian localization findings

## Scope and safety

- `game_original/` was not modified.
- Only `game_work/DontSleepWithTheFishes_Data/level3` was modified.
- `GameAssembly.dll`, `UnityPlayer.dll`, and the executable were not modified.
- A backup was created at `patches/backups/game_work/DontSleepWithTheFishes_Data/level3`.
- The write is logged in `patches/changelog.tsv`.

## Tools and outputs

- `scripts/extract_visible_strings.py` extracts likely visible strings from Unity serialized files.
- `scripts/check_fonts.py` reports Unity and TextMeshPro font assets.
- `scripts/apply_minimal_patch.py` applies only equal-byte-length UTF-8 replacements from `translations/ru.tsv`.
- `extracted/visible_strings.tsv` contains 3076 candidate rows and 660 unique strings.
- `extracted/font_report.tsv` contains the font scan.
- `translations/ru.tsv` contains the Russian table with required columns: `source`, `russian`, `context`, `file`, `status`.

`extracted/visible_strings.tsv` was generated before the smoke-test patch was applied, so it records original English source bytes and offsets for reproducibility.

## Where strings were found

The important visible UI strings are not normal external localization files. They are serialized into Unity scene files, mainly as `TMPro.TextMeshProUGUI` MonoBehaviour data.

Confirmed examples in `level3`:

- `Click To Continue`: `TextMeshProUGUI`, object `4324`, offset `818300`
- `Continue`: `TextMeshProUGUI`, object `4334`, offset `823644`
- `Go To Sleep?`: `TextMeshProUGUI`, object `4339`, offset `826348`
- `Write using your Mouse...`: `TextMeshProUGUI`, object `4344`, offset `828988`
- `No New Entry`: `TextMeshProUGUI`, object `4345`, offset `829532`
- `Not enough energy...`: `TextMeshProUGUI`, object `4350`, offset `832172`
- `Eat Fish!`: `TextMeshProUGUI`, object `4361`, offset `838332`
- `Fish Food`: `TextMeshProUGUI`, object `4363`, offset `839388`
- menu/settings labels also appear as `TextMeshProUGUI` in `level1`, `level2`, `level3`, `level4`, and `level5`.

Gameplay/item strings were found as candidate serialized strings in game MonoBehaviours:

- `Try Fishing`: `Assembly-CSharp:CursorInfoMaker`, `level3`, offset `886560`
- `Useful for fishing!`: `Assembly-CSharp:FishingController`, `level3`, offset `909196`
- `Torn Fishing Net`: `Assembly-CSharp:FishingController`, `level3`, offset `909612`
- `Torn Fishnet`: `Assembly-CSharp:CursorInfoMaker`, `level3` and `level4`
- `Fishnet`: `Assembly-CSharp:CursorInfoMaker`, `level3` and `level4`
- `Fish Can`: `Assembly-CSharp:CursorInfoMaker`, multiple instances in `level4`

`m_Name` is not the primary storage for visible UI text. The confirmed UI rows are inside `TextMeshProUGUI` serialized text fields. Some `m_Name` values are useful context, such as `ClickToContinue`, `CursorTipText`, and `SettingName`, but were not translated.

## Font findings

The game uses TextMeshPro. The shipped TMP font assets appear not to include Cyrillic ranges:

- `LiberationSans SDF`: `32 - 126, 160 - 255, 8192 - 8303, 8364, 8482, 9633`
- `LiberationSans SDF - Fallback`: same range
- `Stimcard SDF` and variants: `32 - 126, 160, 8203, 8230, 9633`
- `Essays1743 SDF`: no useful Cyrillic range reported

This means Russian text may render as missing-glyph boxes even when the string bytes are valid. A full patch should add or configure a TMP fallback font asset with Cyrillic glyphs, or rebuild the TMP SDF font assets with Cyrillic ranges.

## Revert

Use either method:

```sh
cp patches/backups/game_work/DontSleepWithTheFishes_Data/level3 game_work/DontSleepWithTheFishes_Data/level3
```

or restore from the clean copy:

```sh
cp game_original/DontSleepWithTheFishes_Data/level3 game_work/DontSleepWithTheFishes_Data/level3
```

## Install over a clean game

For the current smoke test:

1. Put a clean game copy in `game_work/`.
2. Install UnityPy in a local venv:

   ```sh
   python3 -m venv .venv
   .venv/bin/pip install UnityPy
   ```

3. Run:

   ```sh
   .venv/bin/python scripts/apply_minimal_patch.py
   ```

For an end-user binary install of this test only, replace the clean game's `DontSleepWithTheFishes_Data/level3` with the patched `game_work/DontSleepWithTheFishes_Data/level3`.

For a fuller patch, use the runtime fallback notes in `patches/runtime_translation_fallback.md` until safe asset rebuilding and a Cyrillic TMP font solution are implemented.
