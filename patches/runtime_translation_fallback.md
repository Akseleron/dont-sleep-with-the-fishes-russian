# Runtime Translation Fallback

This is now the primary localization path. Do not expand the equal-byte-length binary patch beyond the existing smoke test. Do not modify `game_original/`, `GameAssembly.dll`, `UnityPlayer.dll`, or the executable manually.

Prepared package:

- Dictionary: `patches/xunity_autotranslator/BepInEx/Translation/ru/Text/_AutoGeneratedTranslations.txt`
- Config template: `patches/xunity_autotranslator/BepInEx/config/AutoTranslatorConfig.ini`
- Download manifest: `patches/xunity_autotranslator/DOWNLOADS.md`
- Test checklist: `patches/xunity_autotranslator/TEST_CHECKLIST.md`

## Current Package Contents

The manual dictionary is now generated from `translations/source_queue.tsv`. It currently contains 569 active translations covering visible strings from `extracted/visible_strings.tsv` for `level1` through `level5`, screenshot-only HUD/menu strings, and runtime gap-fix numeric variants. The source queue also records 31 skipped debug/technical strings that are intentionally excluded from the final XUnity dictionary.

- main menu and difficulty select;
- settings;
- gameplay HUD;
- inventory/item prompts;
- journal;
- sleep prompt and night events;
- fishing prompt, fish names, item names, and item descriptions;
- end/result screen strings.

The config template sets `Endpoint=` empty so the package uses manual translations only and does not call an online translator unless the user changes the config.

## Install Instructions

1. Start from a clean game folder for `DontSleepWithTheFishes_v1_1_2`.
2. Download a BepInEx Unity IL2CPP Windows x64 build from an official source. The BepInEx IL2CPP docs specify the Windows x64 archive for 64-bit Windows IL2CPP games.
3. Record the BepInEx version, download URL, and SHA256 in `patches/xunity_autotranslator/DOWNLOADS.md`.
4. Extract BepInEx into the game root, next to `DontSleepWithTheFishes.exe`.
5. Launch the game once so BepInEx generates `BepInEx/config` and `BepInEx/LogOutput.txt`. First launch can take longer for IL2CPP setup.
6. Download the XUnity.AutoTranslator BepInEx IL2CPP package from the official XUnity.AutoTranslator releases.
7. Record the XUnity.AutoTranslator version, URL, and SHA256.
8. Extract XUnity.AutoTranslator into the game root, preserving its `BepInEx/` layout.
9. Copy the prepared package contents from `patches/xunity_autotranslator/` into the game root. This should add or overwrite only files under `BepInEx/Translation/ru/Text/` and `BepInEx/config/`.
10. Launch the game. Use `ALT+T` to toggle translations, `ALT+R` to reload translation files, and `ALT+U` to try manual hook refresh if IL2CPP misses text.

If text components are missed in IL2CPP, try the XUnity helper plugin noted by the upstream README: `AutoTranslator.IL2CPP.BruteForceFix`. Download it only from the XUnity.AutoTranslator official release assets and record version, URL, and SHA256 before use.

## Font Section

The game uses TextMeshPro. Local scan results in `extracted/font_report.tsv` show no Cyrillic ranges in shipped TMP font assets:

- `LiberationSans SDF`: `32 - 126, 160 - 255, 8192 - 8303, 8364, 8482, 9633`
- `LiberationSans SDF - Fallback`: same range
- `Stimcard SDF` and variants: `32 - 126, 160, 8203, 8230, 9633`
- `Essays1743 SDF`: no Cyrillic range found

If Russian text renders as boxes or blanks, configure a Cyrillic-capable TMP fallback:

1. Build a TextMeshPro font asset bundle with Cyrillic glyphs in a Unity version matching the game as closely as possible. The game files report Unity `6000.2.7f2`.
2. Put the verified asset bundle in the game root.
3. Set this in `BepInEx/config/AutoTranslatorConfig.ini`:

   ```ini
   [Behaviour]
   FallbackFontTextMeshPro=<asset-bundle-filename>
   ```

XUnity documents three TMP font loading paths for `OverrideFontTextMeshPro`: asset bundle path in the game folder, installed system font for TMP 3.2.0+, or a Resources API path such as `Fonts & Materials/LiberationSans SDF`. It recommends `FallbackFontTextMeshPro` for adding glyph coverage. For this game, the built-in Resources TMP fonts do not include Cyrillic, so a custom Cyrillic TMP asset bundle is the practical fix.

Avoid distributing unverified font bundles. If a prebuilt TMP font bundle from an official XUnity release is used, record its release version, URL, and SHA256 in `DOWNLOADS.md`.

## Revert Runtime Package

To remove the runtime localization package, delete the XUnity.AutoTranslator plugin files and the prepared translation/config files from the installed game:

- `BepInEx/Translation/ru/Text/_AutoGeneratedTranslations.txt`
- `BepInEx/config/AutoTranslatorConfig.ini` if it was copied from this package
- XUnity.AutoTranslator plugin folders/files installed from the upstream archive

To remove BepInEx entirely, restore a clean game folder or remove the BepInEx loader files according to the BepInEx package contents used.
